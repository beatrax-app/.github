# beatrax-app/.github

Org-wide community health files, inherited by every repository in the
[beatrax-app](https://github.com/beatrax-app) organisation. Maintained here
once so they never drift between repos.

| File | Applies to |
| ------ | ----------- |
| `profile/README.md` | The org profile page |
| `CONTRIBUTING.md` | Every repo without its own |
| `CODE_OF_CONDUCT.md` | Every repo |
| `SECURITY.md` | Every repo without its own |
| `.github/PULL_REQUEST_TEMPLATE.md` | Every repo's PRs |
| `.github/ISSUE_TEMPLATE/` | Every repo's issues |
| `default.json` | The org-wide Renovate preset (`local>beatrax-app/.github`) |

GitHub only falls back to these when a repository has no file of its own, so a
repo that needs something more specific — `beatrax` does, for the PHP quality
gate — keeps its own copy and wins.
