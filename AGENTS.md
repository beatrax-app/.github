## What this repo is

Org-wide community health files, inherited by every repo in `beatrax-app`:
`CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, the issue and PR
templates, the org profile page, and the shared Renovate preset. Canonical
here — a change lands once and every repo picks it up. See README.md.

## Rules for changes here

- These files are **inherited, not per-repo**. Anything specific to one
  repository belongs in that repository, where its own copy wins.
- Do not add links, addresses, handles or chat invites that cannot be verified
  against an existing file in one of the beatrax repos. The community chat is
  <https://discord.gg/FYuV9CbTHR> — use that invite verbatim and do not
  invent channel names or deep links into it.
- Keep the voice of the existing files: calm, precise, concrete, British
  English, no marketing copy.
- CI here is hygiene only — actionlint, typos, link check, markdownlint. Run
  the same checks locally if you can before pushing.
